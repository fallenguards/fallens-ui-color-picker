# Fallen's UI Color Picker

Recolor the game's whole interface in one place: dark, bronze, or any color you pick, for World of Warcraft: Forever and retail.

Pick a look at first login, or any time with `/fcp` or the minimap button: Dark with its darkness slider, Bronze, or a custom color, textured or flat. Choose which parts of the interface take the color and how dark the backgrounds behind the frames are.

Report a problem or ask for something under **Issues**.

Originally developed as part of [ClassicUI Forever](https://www.curseforge.com/wow/addons/classicui-forever). With the full ClassicUI Forever enabled, the picker stays off, since ClassicUI Forever has the same colors built in.
